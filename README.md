# ai-bot-telegram

بوت تيليجرام ذكاء اصطناعي يعمل مبر موقع openrouter                                    طريقه الاستخدام :                              1- استبدل your-token بتوكن بوت التيليجرام الخاص بك                                       2- استبدل your-openrouter-api-key بمفتاح الapi الخاص بك تحصل عليه من موقع openrouter    3- استبدل developer name باسمك حتى يعرف البوت انك انت المطور                           4- قم برفع و تشغيل البوت في اي استضافة
